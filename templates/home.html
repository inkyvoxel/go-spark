Go from idea to app faster.

Go Spark is a small, practical foundation for server-rendered Go web apps: standard-library HTTP, SQLite, html/template, secure sessions, CSRF protection, and complete email/password auth — with 2FA, passkeys, a background worker, and transactional email all wired in.

First time here?

This page is served by your freshly cloned template. To make it yours:

  1. Run make init — names your project and module path, generates a .env with random secrets, then removes itself.
  2. Run make migrate-up to set up the database.
  3. Run make start and reload this page.

Then add your first feature — a table, page, form, or job — following docs/extending.md.

Documentation

Find these in your repo's docs/ directory:

  • development.md — getting started, commands, conventions
  • architecture.md — package boundaries and design
  • extending.md — recipes for adding features
  • production.md — deployment guide
